# homebrew-tap

Homebrew formulae for [quanchuen](https://github.com/quanchuen) projects.

## Installation

Add the tap:

```sh
brew tap quanchuen/tap
```

Then install a formula:

```sh
brew install resh
```

Alternatively, install directly without tapping first:

```sh
brew install quanchuen/tap/resh
```

## Available formulae

| Formula | Description |
|---------|-------------|
| [`resh`](Formula/resh.rb) | Context-based replacement for zsh and bash shell history ([quanchuen/resh](https://github.com/quanchuen/resh)) |

## Updating

```sh
brew update
brew upgrade resh
```

## Uninstalling

```sh
brew uninstall resh
brew untap quanchuen/tap
```
